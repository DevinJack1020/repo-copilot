# Repo Copilot 实施计划

## 概览

以 Vercel Chatbot 的公开模板能力为基础，交付一个中文代码仓库分析助手。计划优先验证上游模板、数据库和模型网关，再以“导入—索引—分析—引用—评估”为纵向切片逐步完成。

## 架构决策

- 复制明确版本的上游模板文件并保留许可证，不导入其 `.git` 历史，以保持个人提交可读。
- PostgreSQL 全文检索始终可用；向量检索是可选增强，不阻塞无密钥演示。
- 导入和索引用持久化任务状态实现，首版不引入外部队列。
- 所有模型访问经过统一网关；演示模式有显著标识且不可冒充真实结果。

## 阶段一：基础与风险验证

### 任务 1：导入并固定上游模板

**描述：** 获取 Vercel Chatbot 的固定提交，保留 Apache-2.0 许可证和上游说明，调整包名和基础品牌。

**验收标准：**
- [ ] `UPSTREAM.md` 记录仓库、提交 SHA、许可证和导入日期。
- [ ] 应用使用 Repo Copilot 名称，原模板品牌不出现在主界面。
- [ ] 依赖可安装，开发服务器可启动。

**验证：** `pnpm install --frozen-lockfile`；`pnpm dev` 健康检查。  
**依赖：** 无。  
**可能涉及：** `package.json`、`LICENSE`、`UPSTREAM.md`、应用布局与元数据。  
**范围：** M。

### 任务 2：本地环境、数据库与演示种子

**描述：** 提供 PostgreSQL Docker Compose、环境变量示例、迁移命令和可重复种子数据。

**验收标准：**
- [ ] 一条命令可启动数据库并运行迁移。
- [ ] `.env.example` 不包含秘密且解释真实模型和演示模式。
- [ ] 种子命令可重复执行，不产生重复记录。

**验证：** 启动容器、迁移两次、种子两次、运行数据库测试。  
**依赖：** 任务 1。  
**可能涉及：** `compose.yaml`、`.env.example`、数据库配置、迁移与种子脚本。  
**范围：** M。

### 任务 3：模型网关与显式演示模式

**描述：** 封装 OpenAI 兼容模型、超时、流式响应、错误分类和确定性演示回答。

**验收标准：**
- [ ] 无 API Key 时应用进入有标识的演示模式。
- [ ] 真实模型和演示模式返回同一类型化事件协议。
- [ ] 超时和供应商错误不会泄露密钥或堆栈。

**验证：** 模型网关单元测试；模拟成功、超时和错误；手工查看流式演示。  
**依赖：** 任务 1。  
**可能涉及：** `lib/ai/`、模型配置、API 路由、测试夹具。  
**范围：** M。

## 检查点：基础

- [ ] 安装、类型检查、测试和生产构建通过。
- [ ] 有数据库和无模型密钥时均可启动。
- [ ] 上游来源与演示模式清楚可见。

## 阶段二：仓库导入与索引

### 任务 4：安全导入领域模型

**描述：** 建立仓库、导入任务和文件清单模型，并实现文件规则与配额校验。

**验收标准：**
- [ ] 仓库和任务状态可持久化并按用户隔离。
- [ ] 文件数量、大小、深度和类型限制集中配置。
- [ ] `.env`、私钥、二进制、依赖目录和构建产物默认过滤。

**验证：** 数据库集成测试；规则表驱动单元测试。  
**依赖：** 任务 2。  
**可能涉及：** 数据库 schema、迁移、`lib/repositories/`、测试夹具。  
**范围：** M。

### 任务 5：公开 GitHub URL 导入闭环

**描述：** 从受支持的 GitHub URL 获取默认分支压缩包，更新任务进度并展示仓库概览。

**验收标准：**
- [ ] 合法公开仓库可导入，非法主机、超时和超限有可操作提示。
- [ ] 进度、失败原因、文件树和语言统计可在中文界面查看。
- [ ] 重试不会重复创建仓库文件。

**验证：** HTTP 适配器集成测试；Playwright 导入固定样例仓库。  
**依赖：** 任务 4。  
**可能涉及：** GitHub 适配器、导入服务、仓库页面、进度 API、测试。  
**范围：** M。

### 任务 6：ZIP 上传安全闭环

**描述：** 实现 ZIP 上传、隔离解包、安全扫描和与 GitHub 导入共用的清单流程。

**验收标准：**
- [ ] 正常 ZIP 可导入且结果与 GitHub 导入结构一致。
- [ ] 路径穿越、符号链接逃逸和解压超限被拒绝。
- [ ] 临时文件在成功和失败后都能清理。

**验证：** Zip Slip、压缩比、异常编码和清理测试；Playwright 上传样例。  
**依赖：** 任务 4。  
**可能涉及：** 上传路由、ZIP 适配器、安全工具、临时存储、测试。  
**范围：** M。

### 任务 7：代码分块与全文检索

**描述：** 将允许的文本文件按语言和行范围分块，建立全文索引并返回带引用的结果。

**验收标准：**
- [ ] 每个代码块保存文件路径、起止行、哈希和文本。
- [ ] 重复索引根据哈希跳过未变文件。
- [ ] 查询返回相关片段且引用行号可映射回原文件。

**验证：** 分块边界单元测试；固定语料检索集成测试；索引幂等测试。  
**依赖：** 任务 5、6。  
**可能涉及：** `lib/indexing/`、数据库 schema/迁移、检索 API、测试语料。  
**范围：** M。

## 检查点：导入与检索

- [ ] GitHub 和 ZIP 两条导入路径均通过。
- [ ] 安全夹具全部被正确拒绝。
- [ ] 文件树、语言统计和检索引用可手工验证。

## 阶段三：分析与评估

### 任务 8：四类分析任务闭环

**描述：** 为代码解释、错误定位、代码审查和测试生成建立结构化请求、检索上下文和输出展示。

**验收标准：**
- [ ] 四类任务可从仓库页面启动并保存历史。
- [ ] 回答流式展示，引用可点击到文件和行号。
- [ ] 上下文为空、模型失败和取消请求均有清晰状态。

**验证：** 提示构建单元测试；流式 API 集成测试；Playwright 四类任务冒烟测试。  
**依赖：** 任务 3、7。  
**可能涉及：** `lib/analysis/`、聊天 API、工作台组件、引用组件、测试。  
**范围：** M。

### 任务 9：反馈与质量看板

**描述：** 保存有用/无用反馈并聚合成功率、P50/P95 延迟、引用覆盖率和反馈率。

**验收标准：**
- [ ] 每条回答最多保存一个用户当前反馈且可修改。
- [ ] 指标口径在代码和文档中一致。
- [ ] 看板可按时间和任务类型筛选，并标识演示数据。

**验证：** 指标计算单元测试；反馈 API 集成测试；Playwright 看板路径。  
**依赖：** 任务 8。  
**可能涉及：** 反馈 schema/API、指标服务、看板页面、测试。  
**范围：** M。

## 阶段四：交付质量

### 任务 10：响应式界面与可访问性收尾

**描述：** 完成领域化深色中文工作台、移动端抽屉/标签布局、键盘操作和状态可读性。

**验收标准：**
- [ ] 桌面三栏和移动端核心路径无横向溢出。
- [ ] 焦点、标签、对比度和非颜色状态提示通过检查。
- [ ] 加载、空、错误和成功状态均有设计实现。

**验证：** Playwright 多视口；自动可访问性扫描；人工视觉检查。  
**依赖：** 任务 8、9。  
**可能涉及：** 页面布局、共享组件、样式、E2E 测试。  
**范围：** M。

### 任务 11：CI、文档与发布准备

**描述：** 建立 GitHub Actions，完成中英双语 README、架构图、演示素材、部署与贡献说明。

**验收标准：**
- [ ] CI 执行格式、lint、类型、测试和构建。
- [ ] README 从空机器启动路径可复现，并准确区分上游与个人贡献。
- [ ] 不含秘密、伪造数据或无法验证的性能声明。

**验证：** 本地运行 CI 等价命令；秘密扫描；按 README 冷启动验收。  
**依赖：** 任务 10。  
**可能涉及：** `.github/workflows/`、`README*`、`docs/`、截图。  
**范围：** M。

## 完成检查点

- [ ] 所有自动化测试和生产构建通过。
- [ ] 无密钥演示与真实模型配置说明均有效。
- [ ] 核心路径录屏/截图、架构图和测试结果齐全。
- [ ] Git 历史清楚，准备创建远程仓库并推送。

## 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 上游模板版本变化 | 高 | 固定提交 SHA，先完成构建基线 |
| Windows 原生依赖差异 | 中 | 使用 Node LTS、pnpm 与 Docker；CI 在 Linux 验证 |
| ZIP/远程内容安全 | 高 | 严格配额、隔离解包、禁止执行、恶意夹具测试 |
| 模型服务不可用 | 中 | 统一网关、超时、演示模式与确定性测试 |
| 检索效果有限 | 中 | 固定语料评测，全文字段与引用先可验证，向量检索后置 |

## 开放问题

无；当前范围与关键取舍已经确认。
